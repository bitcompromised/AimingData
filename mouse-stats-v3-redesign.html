Valorant data source (the “valorant-match” approach, credential-free)

Implemented the same mechanism used by Overwolf’s VALORANT parser and the gigi project: tail %LocalAppData%\VALORANT\Saved\Logs\ShooterGame.log byte-offset-style (rotation-safe) and run the production regex set over new lines. Strictly read-only. Verified map/agent codename tables against valorant-api.com (this also corrected an error in gigi’s docs: Foxtrot=Breeze, Canyon=Fracture).

What changed, by area

Collector (Python)

  • collector/valorant.py (new) — log tailer + parser + state machine (menu / agent_select / live / postmatch); exposes snapshot via /health and records game_* events into the collector buffer with the same perf_counter clock as input events, so markers land inside the session timeline automatically.
  • collector/main.py — starts the watcher thread (win32), wires game_info into the handler.
  • collector/server.py — /health now includes the game snapshot.

Core (Node)

  • core/server.mjs — game-phase poller (1.5 s) driving automatic session start/stop/cancel; active-session map/agent/matchId patching; GET/POST /api/settings persisted to data/settings.json; POST /api/sessions/:id/notes; DELETE /api/sessions/:id; collector restart/stop/start; per-session stats computed at save; ?meta=1 list mode that strips event payloads.

Web (complete redesign)

  • Dashboard — reference image 1: KPI row (K/D, Headshot %, Flick Latency, Avg Mouse Speed ±σ, Keys Pressed), live input stage (1:1 realtime cursor replay), Round Details / Key Events tabs, Rounds list, Round Analysis (gauge + per-round stats + notes), analytics tabs (Mouse Movement X/Y, Aim Analysis, Keyboard, Heatmap, Frequency Analysis), and the Statistics block (Overview, Aim, Movement, Input, Weapon Analysis) with scope selector. Capture indicator (LIVE pulsing / Idle) replaces “Open Replay”.
  • Sessions — reference image 2 top-left: sessions table (Date, Duration, Matches, Rounds, K/D, Status, Actions with ⋯ menu), Session Details card (map thumbnail, Match ID, mode, map, rounds, duration) and Rounds panel. View All expands the session full-page: back arrow, full-width replay player (~2.2:1) with colored-marker timeline + timestamp labels, play/pause, seek, 0.25×–16× multiplier, fullscreen; lower half holds the nine analysis panels (Mouse Movement X/Y, Mouse Speed vs Time, Aim Analysis, Keyboard, Heatmap, Aim Heatmap, Frequency Analysis, Input Overlay, Round Analysis).
  • Settings — reference image 2 bottom-right minus the Valorant Integration panel: Collector (buffer size, auto start/stop, skip-the-range, restart/stop/start), Display, Data & Storage, Advanced, plus an Input Translation panel (DPI, sensitivity, polling rate; computed eDPI and cm/360) that feeds all chart translations.
  • Analysis engine — analysis.js: exact translation math (deg/s = counts/s × 0.022 × sens — DPI affects physical cm only, eDPI affects in-game rotation), rolling-baseline flick detection with micro-adjustment (mid-flick reversals), correction time and flick-back detection, cursor heatmaps (plain and speed/click-weighted), DFT frequency spectrum, round reconstruction, and a dual-axis chart engine (raw counts/s left, translated °/s right).
